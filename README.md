# TrialReady LK — Administrator Module

This submission contains the Administrator section of the TrialReady LK front-end.

## Included interfaces

- Login
- Administrator dashboard
- Student management and registration
- Calendar and scheduling
- Instructor management
- Vehicle management
- Package management
- Payment management
- Exams and trials
- DMT applications
- Notifications
- Reports and analytics
- Settings

The Instructor and Student account cards are retained on the login screen for interface consistency. Only the Administrator account opens the submitted module.

## Run locally

```bash
npm install
npm run dev
```

Open the local address shown by Vite, normally `http://localhost:5173/`.
